# Руссификатор игры Casualties: Unknown и модов к ней.

## Инфоблок

Данный перевод для Casualties: Unknown является неофициальным и поддерживается сугубо на энтузиазме  

**RU-r - голый руссификатор с цветовой индикацией.**

**RU-r_Extended - Ru-r + частичный перевод кооп мода KrokMP.**

**RU-r_Extenden++ - Добавлены тэги для облегчения поиска предметов, работает без установки UniRuPatch но в крафтовом меню имеет лишние пробелы между названием и кол-вом того, сколько будет скрафчено.**

**UniRuPatch - универсальный руссификатор для работы в паре с Ru-r_Extended++. Фиксит пробел который появляется из-за тэгов. Фиксит проблему отображения рецептов - когда не отображаются все необходимые для крафта ингридиенты. И переводит часть модов. Полный список в конце README.**

**Особенности руссификаторов**

   - Полный перевод доступного текста в игре посредством без использования модов "Ru-r, Ru-r_Extended"

   - Частичная поддержка мода KrokMP "Ru-r_Extended"

   - Цветовая индикация внутри текста для быстрого поиска информации. "Ru-r, Ru-r_Extended"

# Мод UniRuPatch

## Что это такое? 

Модификация призваная расширить возможность перевода модов на русский (или любой другой язык, по этому и "Uni" - "Universal")

## Установка мода

1. Иметь установленный [BepInEx](https://github.com/bepinex/bepinex), он и даёт модам работать.

2. Скачать архив UniRuPatch.zip [со страницы релизов](https://github.com/Pirozechnik/scavgame-locale-RU-r/releases)

3. Распаковать содержиое архива в корень игры

4. Выбрать в настройках языка "Русский Extended++"

5. Вы ещё более прекрасны чем раньше!

## Список поддерживаемых модов

KrokoshaMP mod v4.0.1

Prosthetics v0.8.9

QoL Unknown v1.0.4.6

## FAQ

**В чём разница между файлами "Ru-r" и "Ru-r_Extended?:** В Extended частично добавлены переводы некоторых модов. "Частично" только по тому что не все моды использую ключи которые можно свободно изменять.

**Сломается ли что либо если я поставлю "Ru-r_Extended" без модов?:** Нет, строчки будут лежать мёртвым грузом ожидая подключения соответствующего мода, не влияя на игру в противоположном случае. 

**Зачем нужно тогда 2 разных файла?:** Потому что гладиолус. 

**Теперь появился ещё и RU-r_Extended++, он то зачем нужен?:** Имеет костыльную систему тегов. Необходим для работы UniRuPatch.
