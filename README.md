Русский перевод и адаптация Casualties: Unknown

## Установка

Чтобы установить локаль:
1. Скачать файл локализации "Ru-r.json"
2. Перейти в папку с игрой "Casualties: Unknown"
      Для стима: Библиотека > выбрать игру "Casualties: Unknown" > Нажать на значок шестерёнки справа > Управление > Посмотреть локальные файлы  
3. Поместь JSON файл по пути "*\CasualtiesUnknown_Data\Lang", рядом с файлом EN.json
<img width="492" height="443" alt="steam" src="https://github.com/user-attachments/assets/a75ee168-9c82-4c62-8739-3c365b35db21" />

Если всё выполнено правильно то в главном меню игры, справа сверху появится кнопка "Русский"

Локализация переводит весь текст в игре, незначительно адаптирует фразы и слова для избавления от тавтологии и добавляет цветное выделение в текст для облегчения поиска важной информации в тексте (основном в еде)
