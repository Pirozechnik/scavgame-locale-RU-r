Русский перевод и адаптация Casualties: Unknown

## Установка

Чтобы установить локаль:
1. Скачайте файл локализации "Ru-r.json" или "RU-r_Extended.json" для перевода модов в том числе.
2. Перейдите в папку с игрой "Casualties: Unknown"

   Для стима: Библиотека > Выбрать игру "Casualties: Unknown" > Нажать на значок шестерёнки справа > Управление > Посмотреть локальные файлы  
4. Поместите JSON файл по пути "*Папка с игрой*\CasualtiesUnknown_Data\Lang", рядом с файлом EN.json

Если всё выполнено правильно то в настройках игры, во вкладке "Language" появится кнопка "Русский"

Локализация переводит весь текст в игре, незначительно адаптирует фразы и слова для избавления от тавтологии а так же добавляет цветное выделение в текст для облегчения поиска важной информации в тексте

FAQ:

**В чём разница между файлами "Ru-r" и "Ru-r_Extended?:"** В Extended добавлены переводы некоторых модов.

**Сломается ли что либо если я поставлю "Ru-r_Extended" без модов?:** Нет, строчки будут лежать мёртвым грузом ожидая подключения соответствующего мода, не влияя на игру в противоположном случае. 

**Зачем нужно тогда 2 разных файла?:** Потому что гладиолус.
